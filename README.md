# 우리 용돈기입장 설치 안내

부부 두 사람이 같은 화면을 실시간으로 보면서 쓰는 공유 용돈기입장이에요.
**남편 용돈 / 와이프 용돈 / 공동생활비** 3개 통장이 색으로 구분되고, 수입·지출을 따로 기록해요.

- 지금 상태 그대로 `index.html`을 열면 **체험 모드**(그 기기에만 저장)로 동작해요. 화면 구경용이에요.
- 두 사람이 공유하려면 아래 **1~4단계**를 한 번만 하면 돼요. (약 20분)

---

## 컴퓨터에서 폰 화면처럼 보면서 수정하기

1. **Windows**: 폴더의 `start.bat` 더블클릭 / **맥**: 터미널에서 `./start.command`
   (Python이 설치되어 있어야 해요. 없으면 https://www.python.org/downloads/ 에서 설치하고, 설치할 때 **Add python.exe to PATH**를 체크하세요.)
2. 브라우저에 폰 모양 미리보기(`http://localhost:8080/preview.html`)가 자동으로 열려요.
3. `index.html`을 메모장/VS Code로 고치고 **저장**하면 미리보기가 1초 안에 자동으로 바뀌어요.
4. 위쪽에서 기종(아이폰/갤럭시), 밝은/어두운 화면을 바꿔 볼 수 있고, '체험 데이터 지우기'로 입력해 둔 연습 데이터를 비울 수 있어요.
5. 끌 때는 검은 창(start.bat)을 닫으면 돼요.

> `index.html`을 더블클릭해서 바로 열면 일부 기능(오프라인 저장, Firebase 연결)이 동작하지 않아요. 꼭 위 방법으로 여세요.
> 크롬만으로 보고 싶다면, `localhost:8080/index.html`을 열고 `F12` → `Ctrl+Shift+M`(기기 모드)을 눌러도 같은 효과예요.

개발이 끝나면 아래 1~4단계(Firebase 연결, 웹 주소 만들기) → 폰 설치(또는 APK 변환) 순서로 진행하세요.

## 1단계. Firebase 프로젝트 만들기 (무료)

1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인
2. **프로젝트 추가** → 이름 아무거나(예: `yongdon`) → 구글 애널리틱스는 **사용 안 함** → 만들기
3. 프로젝트 화면에서 `</>` (웹 앱 추가) 클릭 → 앱 이름 입력 → **앱 등록**
4. 화면에 나오는 `firebaseConfig = { ... }` 값을 복사해서 **`firebase-config.js`** 파일의 `YOUR_...` 부분에 붙여넣고 저장

## 2단계. 로그인 계정 2개 만들기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **이메일/비밀번호** 사용 설정 → 저장
3. **사용자** 탭 → **사용자 추가**로 계정 2개 생성
   - 본인 이메일 + 비밀번호
   - 와이프 이메일 + 비밀번호
   (실제 쓰는 이메일이 아니어도 돼요. 예: `me@home.com`. 단, 비밀번호는 꼭 기억해 두세요.)

## 3단계. 데이터베이스 만들고 보안 설정

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치는 **asia-northeast3 (서울)** 선택 → **프로덕션 모드**로 시작
3. **규칙** 탭을 열고, `firestore.rules` 파일 내용을 전부 붙여넣은 뒤
   `남편이메일@gmail.com`, `와이프이메일@gmail.com` 을 **2단계에서 만든 두 이메일**로 바꾸고 **게시**
   → 이 두 계정만 데이터를 보고 쓸 수 있어요. 다른 사람은 주소를 알아도 못 봐요.

## 4단계. 인터넷에 올려서 주소 만들기

폰에서 열려면 웹 주소가 필요해요. 둘 중 편한 방법을 고르세요.

**방법 A. Netlify Drop (가장 쉬움)**
1. https://app.netlify.com/drop 접속 (가입 필요)
2. 이 폴더 전체를 화면에 드래그 앤 드롭
3. 나오는 주소(예: `https://xxxx.netlify.app`)를 와이프에게 전달
4. 파일을 고쳐서 다시 올릴 땐 같은 사이트의 **Deploys** 탭에 폴더를 다시 드롭

**방법 B. Firebase Hosting**
1. PC에 Node.js 설치 후 터미널에서 `npm i -g firebase-tools` → `firebase login`
2. 이 폴더에서 `firebase init hosting` (기존 `firebase.json` 유지, public 폴더는 `.`) → `firebase deploy`
3. 나오는 `https://프로젝트이름.web.app` 주소 사용

## 폰에 설치하기

### 와이프 (아이폰)
1. **Safari**로 위 주소 접속 (크롬 말고 사파리!)
2. 아래 가운데 **공유 버튼(□↑)** → **홈 화면에 추가** → 추가
3. 홈 화면의 아이콘으로 열면 앱처럼 전체화면으로 열려요
4. 처음 한 번 이메일/비밀번호로 로그인 → "이 폰은 누구 거예요?"에서 자기 이름 선택
   (한 번 고르면 그 로그인 계정이 남편/와이프로 연결돼서, 폰을 바꾸거나 다시 로그인해도 다시 묻지 않아요.)

### 본인 (안드로이드)
- **간단한 방법**: 크롬으로 주소 접속 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가). 이것도 앱처럼 설치돼요.
- **APK 파일로 받고 싶다면**: https://www.pwabuilder.com 에 웹 주소를 넣고 **Package for stores → Android**로 받으면 APK(또는 AAB)가 만들어져요.
  - 처음 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 켜야 할 수 있어요.

## 사용 방법

- 위쪽 **3개 카드**: 각 통장의 잔액(전체 누적)과 이번 달 수입/지출. 카드를 누르면 그 통장 내역만 필터돼요.
- 오른쪽 아래 **＋**: 수입/지출, 통장, 금액, 항목, 날짜, 메모 입력. 통장은 **내 용돈**(로그인한 사람, 기본 선택됨)과 **공동생활비** 두 가지예요. 공동생활비를 고르지 않으면 내 용돈으로 기록돼요. **수입**을 고르면 같은 두 버튼이 **용돈**(내 용돈 통장)과 **월급**(공동생활비 통장)으로 바뀌어요.
- **항목 직접 추가**: 항목 맨 아래 **＋ 직접 입력**을 고르고 이름을 쓰면 새 항목이 생겨요. 직접 만든 항목은 아이콘 없이 이름의 첫 글자로 표시되고, 통계에서는 이름이 다르면 각각 따로 집계돼요. 한 번 만들면 다음부터 목록에 나오고, 상대방 폰에도 똑같이 보여요. 설정 탭의 "내가 만든 항목"에서 지울 수 있어요. (지워도 이미 쓴 내역은 그대로예요.)
- 내역을 누르면 **수정/삭제**. 내역을 **옆으로 밀면(좌우 모두)** 빨간 **삭제** 버튼이 나오고, 끝까지 밀면 바로 삭제돼요. 삭제하면 되돌릴 수 없으니 주의하세요. (달력 탭의 날짜별 목록에서도 똑같이 돼요.)
- **화면 좌우 스와이프**: 내역 → 달력 → 통계 → 설정 순서로, 화면을 왼쪽으로 밀면 다음 탭, 오른쪽으로 밀면 이전 탭으로 이동해요. 내역 줄 위에서 미는 동작은 삭제용이라, 줄이 아닌 곳(위쪽 카드, 빈 공간, 날짜 줄 등)에서 밀어 주세요.
- **달력** 탭: 날짜별 수입/지출이 표시되고, 날짜를 누르면 그날 내역이 아래에 나와요. 그 자리에서 바로 추가도 돼요.
- **반복 내역** (설정 탭): 월세·통신비·구독료처럼 매달 같은 날 생기는 수입/지출을 등록하면, 그날이 되어 앱을 열 때 내역에 자동으로 들어가요. 서버가 대신 움직이는 게 아니라서, 두 분 중 누군가 앱을 열어야 들어가요. (며칠 늦게 열어도 빠진 달은 채워져요.)
- **통계** 탭: 달별 항목 지출/수입 비율, 통장별 비율
- **설정** 탭: 이름 바꾸기, 이 폰의 주인 선택, 엑셀(CSV) 내보내기
- 한 사람이 입력하면 상대 화면에 바로 반영돼요. 인터넷이 잠깐 끊겨도 입력은 폰에 저장됐다가 연결되면 자동으로 올라가요.

## 참고

- `firebase-config.js`의 값은 비밀번호가 아니에요. 보안은 3단계 규칙(두 이메일만 허용)이 지켜줘요.
- 무료 사용량(Spark 요금제)으로 부부 둘이 쓰기엔 충분해요.
- 화면을 고쳐서 다시 올리면, 앱을 한두 번 껐다 켜면 새 버전으로 바뀌어요.
